## 3. Professional Experience

Your descriptions are detailed, but they read like task lists. Recruiters skim for **achievements, scope, and impact**.

### Fix:

* Use **action + result** structure.
* Quantify impact when possible (time saved, cost reduced, systems migrated, data volumes, number of APIs).
* Highlight **leadership, cross-team collaboration, mentoring, client impact**.

**Example before → after:**

* *“Designed and developed RAML REST API specifications in Design Center.”*
  → *“Designed 15+ REST API specifications in MuleSoft Design Center, enabling secure Salesforce and SQL Server integrations used by 500+ daily transactions.”*
